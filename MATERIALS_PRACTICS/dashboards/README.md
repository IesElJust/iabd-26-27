# Dashboards - BiciTierra Market Predicció Comercial

## Materials

- `01_briefing_powerbi.md`
- `02_kpis_i_visuals.md`
- `03_model_taules.md`

## Finalitat

Donar una guia mínima per construir un dashboard executiu amb `Power BI` o una eina equivalent.

## Com usar-los

- alumnat: dissenyar primer les preguntes de negoci i després escollir visuals

## Connexió amb la capa analítica nova

- els visuals del dashboard han d'eixir de preguntes ja explorades al notebook amb `Pandas` i visualització prèvia
- si el notebook detecta segments, outliers o factors clau, el dashboard ha de decidir quins d'eixos resultats mereixen vista executiva
- no convé posar al dashboard gràfics que no hagen tingut abans una lectura analítica clara

## Relació amb la resta de materials

- el dashboard no substituïx l'`EDA` ni la comparativa de models; només n'hauria de mostrar la part que ajuda a decidir
- si una visual funciona només perquè queda bonica, però no canvia cap lectura de negoci, no hauria d'entrar al panell final

## Què hauria d'eixir d'ací

- KPIs prioritzats
- vista executiva llegible en pocs segons
- connexió clara entre model i recomanació
