# Notebooks de BiciTierra Market

El [document de treball](../../index.md) determina què cal fer cada setmana.

- `01_eda.ipynb`: setmana 1; revisió de qualitat en setmana 2.
- `02_modelatge_baseline.ipynb`: apartats 1–2 en setmana 2; apartats 3–4 en setmana 3; apartats 5–6 en setmana 5.
- `03_segmentacio.ipynb`: setmana 4. Inclou una referència per regles; les ampliacions de clustering estan en les píndoles.

Obriu els notebooks amb la carpeta de treball situada ací. Les dades estan en `../dades/`. La base executa amb pandas i NumPy; Jupyter és l’entorn d’edició. Altres eines de les píndoles requerixen les dependències que indiquen.

Manteniu els CSV originals i deseu les vostres conclusions, transformacions i prediccions en el repositori de l’equip. Les marques setmanals no impedixen tècnicament executar tot el notebook: respecteu el punt d’aturada abans de la prova reservada.
