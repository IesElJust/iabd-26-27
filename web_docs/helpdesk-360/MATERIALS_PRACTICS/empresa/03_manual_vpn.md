# Manual Basic De VPN

Per accedir a recursos interns des de fora de l'oficina:

1. Instal.la el client indicat pel departament TIC.
2. Inicia sessió amb usuari corporatiu.
3. Comprova que la MFA estiga activa.
4. Si apareix error de certificat, cal renovar-lo des del portal intern.

Errors habituals:

- credencials caducades
- client desactualitzat
- connexio bloquejada per falta de MFA
