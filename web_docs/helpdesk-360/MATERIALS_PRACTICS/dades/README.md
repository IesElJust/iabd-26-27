# Dataset Helpdesk

## Objectiu docent

El conjunt esta pensat per a treballar:

- classificacio de tickets
- neteja de text
- deteccio de duplicats
- tractament d'etiquetes inconsistents

## Bruticia intencionada

- variants de redaccio del mateix problema
- una fila amb `estat` en angles (`pending`)
- duplicat practic en `T023` i `T024`
- grafies irregulars i abreviatures
- un cas amb accent residual al text

## Tasques suggerides

- normalitzar etiquetes
- detectar duplicats o quasi duplicats
- revisar si la categoria sospitada es coherent
