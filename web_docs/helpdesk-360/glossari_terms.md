# Glossari del helpdesk

| Terme | Significat |
|---|---|
| Baseline | Enfocament inicial amb què comparar millores |
| Chunk | Fragment documental que conserva una unitat de sentit |
| Derivació | Trasllat explícit a revisió humana quan el sistema no pot resoldre |
| Embedding | Vector que representa un contingut |
| F1 macro | Mitjana de F1 donant el mateix pes a cada classe |
| Fuita de dades | Informació de prova que influïx en l'entrenament |
| Guardrail | Control que limita el comportament del sistema |
| LLM | Model de llenguatge gran (Large Language Model) |
| PLN | Processament de Llenguatge Natural
| RAG | Generació de resposta amb context recuperat |
| Recuperació | Selecció de fragments per a una pregunta |
| TF-IDF | Representació numèrica segons freqüència de termes |
| Taxonomia | Categories i criteris per assignar-les |
| Ticket | Petició o incidència de suport |
| Traçabilitat | Possibilitat de localitzar l'origen de la resposta |
