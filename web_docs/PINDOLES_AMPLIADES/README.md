# Píndoles ampliades

Comença per l’[índex general](docs/index.md): accés per a alumnat i professorat, onze unitats, preparació de l’entorn i connexió amb les setmanes.

Consulta el [registre de validació](docs/VALIDACIO.md) per conéixer les comprovacions i els seus límits.

Per a una presentació local amb MkDocs Material, des d’esta carpeta i amb un entorn virtual activat:

```bash
python -m pip install -r docs/requirements-presentacio.txt
mkdocs serve
```

Les unitats estan en `docs/`; els programes es poden executar sense generar la presentació.
